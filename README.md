# Kuno Optimizer

A beautiful PC optimizer for Windows — clean temp files, manage startup, monitor your system, and apply performance presets.

Made by **Kuno**.

## Features

- **System Dashboard** — CPU, RAM, disk usage, uptime at a glance
- **Quick Cleanup** — Remove temp files, browser cache, prefetch
- **Startup Manager** — View and disable startup programs
- **Performance Presets** — Balanced, Gaming, Work, Battery Saver
- **Login System** — Personal profiles for each user
- **Apple-inspired UI** — Frosted glass, dark theme, smooth animations

## Download

Grab the latest build from [Releases](https://github.com/Kunosaki/kuno-optimizer/releases).

## Build from source

```bash
git clone https://github.com/Kunosaki/kuno-optimizer.git
cd kuno-optimizer
npm install
npm run build:win
```
